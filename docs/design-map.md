## Повторяющаяся структура → один компонент

- **Feature (3, 4, 5)** — один компонент `feature` с модификатором `feature--reverse` для 02.
  Состав: большой номер (240px, opacity 0.1), тэглайн с линией, H2, текст, ссылка «read more» со стрелкой, фото 566×720.
- **Тэглайн с линией 72×2** — в Hero и во всех Feature: компонент `tagline`.
- **Логотип MNTN** — в Header и Footer: один компонент `logo` (в макете собран из 4 текстовых слоёв — верстаю одним текстом).
- **Колонка ссылок футера** — 2 шт.: компонент `footer-nav`.
- **Стрелка** `icon/navigation/arrow_downward_24px` (#1:98) — «scroll down» (вниз, белая) и «read more» (повёрнута −90°, акцентная): один SVG.

## Дешевле картинкой, чем версткой

- Три слоя гор (HG/MG/VG) — растровые изображения, идут фоном.
- Фото в Feature 01/02/03 — растр. У 02 кроп (`cropTransform`, suffix `4f9aa3`).
- Иконки Instagram, Twitter, Account, стрелка — SVG.
- Слайдер справа — полоса (2 прямоугольника) верстается CSS, не картинкой.

## Особенности

- В макете нет auto layout у Header, Social, Slider, Footer — это группы с абсолютными координатами. Раскладку перевожу на flex/grid, координаты беру как целевые для замера.
- Навигация хедера центрирована по ширине 1760 (центр ≈ x 880).
- «Follow us» повёрнут на 90°.
- Тексты с `textCase` в макете набраны не в том регистре («GEt Started», «where you go is the key») — оставляю исходник дословно, регистр через `text-transform`.
