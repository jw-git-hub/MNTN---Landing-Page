# Прогресс вёрстки

## Готово

| Секция | Коммит | Замер 1920 |
|---|---|---|
| Токены | `styles: design tokens` | — |
| Ассеты, шрифты, примитивы, LICENSE | `feat: assets, fonts, base primitives…` | — |
| Header | `feat(header)` | в допуске, кроме Account (+3px, осознанно) |
| Hero + сцена + Social + Slider | `feat(hero)` | в допуске |
| Feature 01/02/03 | `feat(features)` | в допуске |
| Footer | `feat(footer)` | в допуске, кроме копирайта (−6px, осознанно) |
| Сдвиг текста Hero | `fix(hero)` | под горами только ≥1920 |
| Адаптив телефон/планшет + анимация карточек | `feat(responsive)` | 1280 и 1920 — геометрия без изменений |

Высота страницы на 1920 — 4600px, совпадает с фреймом.

## Принятые решения

- Файлы стилей: `tokens.css`, `fonts.css`, `main.css` (база и примитивы), `sections/*.css` — по файлу на секцию.
- Слои гор масштабируются от ширины `.page` через `--scenery-unit` (container query units), минимум 900px.
- Текст Hero лежит под горами на ≥1920 (как в Figma), уже — поверх: на 1280 горы перекрывали заголовок.
- Feature — один компонент, `feature--reverse` меняет колонки местами через `order`, порядок чтения не меняется.
- Градиент Hero пересчитан из `gradientHandlePositions`: −19.7°, стопы 31.1% / 108.9%.
- Иконки — SVG-спрайт `assets/icons/sprite.svg` с `currentColor`.
- Адаптива в макете не было, сделан сверх макета: до 767 — одна колонка, 768–1279 — две колонки
  с чередованием фото (`--feature-image-share` 45%, gap 40px, gutter 40px), футер в две колонки.
  На <1280 тэглайн короче (линия 40px, трекинг 0.2em), чтобы длинные тэглайны не переносились.
- Анимация появления Feature: `scripts/reveal.js` (IntersectionObserver, порог 15%) ставит
  `has-reveal` / `is-revealed`; нечётные слева, чётные справа; переход только на появление.
  Отключена при `prefers-reduced-motion`, без JS карточки видны.

## Осознанные расхождения

- «Account» 18px вместо 17px (единый кегль UI).
- Копирайт в макете сдвинут на 6px вправо от колонки — не повторяю.

## Побочные эффекты, не решения

- Хвостовой трекинг тэглайнов: CSS добавляет 6px после последней буквы, на положение не влияет.
- Двойной пробел в «What level of  hiker are you?» схлопывается в HTML.

## Шрифты

- Подключены все начертания макета: Gilroy 500/700/800, Chronicle Display 600/700 (woff2). Перемер после подключения: логотип 108.2 (макет 108), номера 01/02/03 в пределах 1px, ссылки и копирайт футера в пределах 1px.
- Глиф-бокс Gilroy (TTF-метрики) 18px против 22px в Figma — строчные боксы и центры текста совпадают, это артефакт замера текстового диапазона.

## Открытые вопросы

- Адресов в макете нет. Решено без согласования: Equipment → раздел 02, Blog → раздел 01,
  About us → футер, соцсети → главные страницы Instagram и Twitter, остальное
  (Account, «read more», ссылки футера) → заглушка `soon.html`.
- `alt` у трёх фотографий написаны при вёрстке, а не взяты из макета.
- Мобильная и планшетная версии и анимация карточек придуманы: десктопный фрейм 1920 —
  единственный в макете. Требуют согласования с дизайнером.
- Опечатки оригинала («chafe wif», «junction..», двойной пробел
  в «What level of  hiker») перенесены дословно и ждут решения владельца текста.
